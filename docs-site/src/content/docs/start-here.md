Helprr runs in Docker on a machine at home, next to the apps it talks to, and you open it
in a browser or add it to your phone's home screen.

## What you need

- A computer that stays on, with Docker Engine and the Compose plugin
  (Docker Compose 2.18 or newer).
- At least one of Sonarr, Radarr, Lidarr, qBittorrent, Prowlarr, Jellyfin or Seerr, and
  its address and API key.
- For push notifications on an iPhone: iOS 26 or newer, and Helprr reached over HTTPS.
