---
title: Radarr
description: Connect Radarr to Helprr.
---

**Usual port:** 7878. **Key:** in Radarr, **Settings → General → API Key**.

**What it adds:** Films, collections, the calendar, the queue and activity, wanted and missing films, adding new films, and file actions.

In **Settings → Instances**, tap **+ Add Radarr instance** (or **Add its key**, if Find
apps on this network found it). Enter a name (any label,
such as Main), the address ([which one?](/helprr/connect/#which-address-to-use)) and the
key, then **Test**, and **Save** once it works.

Connect a second Radarr (for 4K, for example) as its own instance.
