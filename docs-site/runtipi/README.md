# Helprr for Runtipi

A [Runtipi](https://runtipi.io) app store with one app: [Helprr](https://github.com/SaiBarathR/helprr).

In Runtipi, open **Settings → App Stores → Add appstore**, and enter
`https://github.com/SaiBarathR/helprr-runtipi`. The
[guide](https://saibarathr.github.io/helprr/install/runtipi/) has the rest.

This repository is written by Helprr's release from its `docker-compose.yml`
(`docs-site/scripts/runtipi-store.mjs` in the Helprr repository); changes made here by
hand are replaced by the next release.
